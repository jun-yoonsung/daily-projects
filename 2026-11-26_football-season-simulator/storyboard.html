축구 리그 시즌 시뮬레이터 — 스토리보드

PRD 사용자 시나리오 1~5를 장면(컷)별로 보여줍니다. 모든 팀과 데이터는 가상입니다.

$ python tools/generate_data.py --seed 2026
teams.csv   : 12 teams
matches.csv : 132 matches (played 90, remaining 42)
저장 위치    : data/
장면 0

가상 데이터 준비

더블 라운드로빈 일정(22라운드)을 만들고, 앞 15라운드는 숨은 "진짜 전력"으로 결과를 생성합니다. 저장소에 이미 포함되어 있어 보통은 건너뜁니다.

팀 12개→원형 방식 일정→15라운드 결과→CSV

전환 조건: data/ 폴더에 CSV 두 개가 있으면 장면 1로.

현재 순위 보기 (시나리오 1)

치른 경기만으로 순위표를 계산합니다. 정렬은 승점 → 득실차 → 다득점 → 팀 이름 순입니다.

전환 조건: "남은 경기를 고려하면?"이 궁금해지면 장면 2(전력)로.

$ python -m fsim strength

팀 전력 확인 (시나리오 2)

득점·실점을 리그 평균 대비 비율로 바꾸고 경기 수가 적은 영향을 줄이기 위해 1.0 쪽으로 축소 보정합니다.

홈 λ = 기본 × 홈어드밴티지 × 공격[홈] × 수비[원정]

전환 조건: 전력 값이 준비되면 장면 3(시뮬레이션)으로.

시즌 시뮬레이션 (시나리오 3)

남은 각 경기의 양 팀 득점을 포아송 분포로 뽑아 시즌을 끝까지 진행하고, 최종 순위를 반복 집계합니다. 같은 시드면 같은 결과입니다.

전환 조건: 결과를 공유하고 싶으면 --html 을 붙여 장면 4로.

장면 4

HTML 리포트 공유 (시나리오 4)

simulate --html report.html 이 확률 막대와 순위 분포 히트맵(진할수록 확률 높음)이 있는 단일 파일을 저장합니다. 외부 CSS/JS 없이 어디서나 열립니다.

전환 조건: 리포트를 열어 확인하면 흐름 종료. 데이터를 직접 고쳤다면 장면 5를 거칠 수 있습니다.

$ python -m fsim table --data broken/
데이터 오류: matches.csv 7번째 줄: 알 수 없는 팀 ID 'XXX'
$ echo $?
1
장면 5

잘못된 데이터 (시나리오 5)

없는 팀 ID, 음수/문자 점수, 한쪽만 입력된 점수, 중복 경기를 줄 번호와 함께 알려주고 종료 코드 1로 끝납니다.

전환 조건: CSV를 고치고 다시 장면 1부터 실행.

모든 팀 이름과 경기 결과는 가상 데이터입니다.
