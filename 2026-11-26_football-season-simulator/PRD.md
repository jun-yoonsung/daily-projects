# PRD — 축구 리그 시즌 시뮬레이터 (Football Season Simulator)

## 1. 배경 / 문제 정의
시즌 중반의 축구 리그 순위표는 "지금 몇 위인가"만 알려줄 뿐, "남은 경기를 고려하면 우승·강등 가능성이 얼마나 되는가"는 알려주지 않습니다.
남은 일정의 난이도(강팀과 몇 번 붙는지)와 팀 전력을 함께 고려하려면 확률 모델과 반복 시뮬레이션이 필요합니다.
이 프로젝트는 지금까지의 경기 결과로 팀 전력을 추정하고, 남은 경기를 수만 번 시뮬레이션해 팀별 최종 순위 확률을 계산하는 CLI 도구를 만듭니다.

## 2. 목표 / 비목표
### 목표
- 경기 결과 CSV로 현재 순위표(승점·득실차·다득점 기준)를 정확히 계산한다.
- 치른 경기의 득점/실점으로 팀별 공격력·수비력을 추정한다.
- 포아송(Poisson) 득점 모델 + 홈 어드밴티지로 남은 경기를 몬테카를로 시뮬레이션한다.
- 팀별 우승 / 상위 4위(대륙 대회 진출) / 강등(하위 2팀) 확률과 예상 최종 승점, 순위 분포를 보여준다.
- 같은 시드면 같은 결과가 나오도록 재현 가능하게 한다.
- 결과를 외부 의존성 없는 단일 HTML 리포트로도 저장한다.

### 비목표 (이번 범위에서 하지 않음)
- 실제 리그 데이터 수집/크롤링, 외부 API 연동 (가상 데이터만 사용)
- 선수 단위 모델링(부상, 이적, 출전 정지 등)
- 승부차기·컵 대회·플레이오프 방식
- 웹 서버/GUI 애플리케이션 (HTML 리포트는 정적 파일)
- 머신러닝 기반 정밀 예측 모델(Dixon-Coles 보정 등)은 선택 기능으로 미룸

## 3. 대상 사용자
- 축구 팬 중 "우리 팀이 강등될 확률"을 숫자로 보고 싶은 사람
- 확률 모델·몬테카를로 시뮬레이션을 예제로 배우고 싶은 개발자/학생

## 4. 핵심 기능 목록
| ID | 기능 | 우선순위 |
|----|------|----------|
| F1 | 데이터 로드·검증: `teams.csv`, `matches.csv` 읽기, 잘못된 팀 ID·점수·중복 경기 오류 보고 | 필수 |
| F2 | 현재 순위표 계산: 승 3 / 무 1 / 패 0, 정렬 기준 승점 → 득실차 → 다득점 → 팀 이름 | 필수 |
| F3 | 팀 전력 추정: 공격력·수비력(리그 평균 대비 비율, 사전값으로 축소 보정), 홈 어드밴티지 | 필수 |
| F4 | 잔여 경기 시뮬레이션: 포아송 득점 샘플링, 반복 횟수·시드 지정, 재현 가능 | 필수 |
| F5 | 확률 집계: 우승·상위 4위·강등 확률, 평균 최종 승점, 팀별 순위 분포 | 필수 |
| F6 | CLI: `table`, `strength`, `simulate` 서브커맨드 | 필수 |
| F7 | HTML 리포트: `simulate --html 파일` 로 순위 확률 표·막대·히트맵이 있는 단일 HTML 저장 | 필수 |
| F8 | 가상 데이터 생성기: 12팀 더블 라운드로빈 일정 + 앞 15라운드 결과 생성(시드 고정) | 필수 |
| F9 | 단일 경기 예측: `predict 홈팀 원정팀` → 승/무/패 확률, 최빈 스코어 | 선택 |
| F10 | What-if: 특정 잔여 경기 결과를 고정하고 시뮬레이션 (`--fix "H-A=2-1"`, 여러 번 지정 가능) | 선택 |
| F11 | 백테스트: 앞 N라운드로 추정한 모델로 그 뒤 치른 경기의 승/무/패를 예측해 로그 손실·Brier 점수·적중률을 기준 모델(균등 1/3, 학습 구간 빈도)과 비교 | 선택 |

## 5. 사용자 시나리오
1. **현재 순위 보기**: 사용자가 `python -m fsim table` 을 실행 → 현재 순위표(경기수, 승/무/패, 득실, 승점)가 터미널에 출력된다.
2. **전력 확인**: `python -m fsim strength` → 팀별 공격력·수비력·홈 어드밴티지가 표로 나온다.
3. **시즌 시뮬레이션**: `python -m fsim simulate --n 10000 --seed 42` → 진행 상황 없이 몇 초 안에 팀별 우승/상위4/강등 확률과 예상 승점 표가 출력된다.
4. **리포트 공유**: `--html report.html` 옵션을 붙이면 브라우저로 열 수 있는 리포트가 저장된다. 사용자는 순위 분포 히트맵에서 "우리 팀이 각 순위로 끝날 확률"을 본다.
5. **잘못된 데이터**: CSV에 없는 팀 ID가 있으면 몇 번째 줄이 잘못됐는지 알려주고 종료 코드 1로 끝난다.
6. **단일 경기 예측**: `python -m fsim predict HAN BUS` → 두 팀의 기대 득점, 홈 승/무/원정 승 확률, 가장 가능성 높은 스코어 상위 5개가 출력된다.
7. **What-if**: `python -m fsim simulate --seed 42 --fix "JEJ-HAN=0-2"` → 해당 잔여 경기를 0-2로 고정한 뒤 시뮬레이션한다. 고정 경기 목록이 표 위에 표시된다. 이미 치른 경기나 없는 경기를 고정하면 오류(종료 코드 1).
8. **백테스트**: `python -m fsim backtest --train-rounds 10` → 1~10라운드로 전력을 추정하고 11라운드 이후 치른 경기를 예측해 모델과 기준 모델의 로그 손실·Brier·적중률을 비교한다.

## 6. 입력 · 출력 · 데이터 구조
### 입력
- `data/teams.csv`: `id,name` (예: `HAN,한강 FC`)
- `data/matches.csv`: `round,home,away,home_goals,away_goals` — 치르지 않은 경기는 점수 칸을 비워 둔다.

### 내부 데이터 구조
- `Team(id, name)`
- `Match(round, home, away, home_goals: int|None, away_goals: int|None)` — `played` 속성
- `Standing(team, played, win, draw, loss, gf, ga, gd, points)`
- `Strength(attack: dict, defense: dict, home_adv: float, base_rate: float)`
  - 기대 득점: 홈 λ = base × home_adv × attack[홈] × defense[원정], 원정 μ = base × attack[원정] × defense[홈]
- `SimResult(n, title_prob, top4_prob, releg_prob, mean_points, pos_dist[team][pos])`
- `MatchPrediction(home, away, lam, mu, p_home, p_draw, p_away, top_scores)` — 0~10골 포아송 스코어 행렬(합이 1이 되도록 정규화)로 계산
- `BacktestResult(train_rounds, n_test, model/uniform/freq 각각의 log_loss·brier·accuracy)`

### 출력
- 터미널 표(고정폭 정렬), HTML 리포트 파일(외부 CSS/JS/CDN 없음)

## 7. 기술 스택과 선택 이유
- **Python 3.10+ 표준 라이브러리만**(csv, random, math, argparse, html): 설치 없이 바로 실행, 저장소에 의존성 부담 없음.
- **포아송 모델**: 축구 득점 분포를 간단하면서도 잘 근사하는 고전적 모델로, 설명하기 쉽다.
- **unittest**: 표준 라이브러리 테스트 프레임워크.

## 9. 리스크 / 제약
- 경기 수가 적으면 전력 추정이 불안정 → 사전값(1.0)으로 축소(shrinkage)해 극단값을 완화한다.
- 순수 Python 반복은 느릴 수 있음 → 10,000회 × 42경기 기준 10초 이내를 목표로 하고, 포아송 샘플링을 가볍게 구현한다.
- 동률 처리 규칙은 리그마다 다름 → 이 프로젝트는 승점 → 득실차 → 다득점 → (시뮬레이션에서는) 무작위 순서로 고정한다. 현재 순위표의 최종 동률은 팀 이름 순.
- 모든 데이터는 **가상 데이터**이며 실제 리그·구단과 무관하다.
